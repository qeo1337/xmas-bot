# 🎄 Новогодний ивент: Telegram-бот

Командный ивент на декабрь: каждый участник украшает свою ёлку шарами,
закидывает других снежками и растит серию ежедневных украшений.
Площадка — Telegram (inline-кнопки + команды), стек: Python + aiogram 3 + PostgreSQL + Docker.

## Игровая механика

- **Украшение**: раз в 3 часа (`DECOR_COOLDOWN_HOURS`) участник вешает **шар** на ёлку.
  База — 1 шар, бонус за серию (1→+0, 2→+1, 3→+2, 5→+3, 7→+5, 14→+7, 21→+10, 28→+12 шаров).
  Ночное украшение (вне 08:00–23:59) вешает шары, но **не растит серию**.
- **Анонимный рейтинг**: участники видят только своё место и отставание от лидера
  («до лидера N шаров»). Полный топ скрыт до финала; полный reveal — админ-командой
  в конце ивента.
- **Ачивка за участие**: 🎄 «Я в деле!» выдаётся при регистрации автоматически.
- **Снежки**: 3 в сутки, уведомление цели.
- **Прозрачность для организатора**: каждое действие пишется в `event_log`
  (кто/что/когда) + `/admin_list` с логинами и полными данными.

## Команды

**Пользователи** (всё дублируется кнопками из меню `/start`):
| Команда | Действие |
|---|---|
| `/start` | регистрация / меню |
| `/decor` | повесить шар |
| `/snow <имя>` | кинуть снежок; без аргумента — список участников |
| `/top` | моё место в номинациях (анонимно) |
| `/me` | моя статистика и ачивки |

**Админы**:
| Команда | Действие |
|---|---|
| `/admin` (`/admin_stats`) | сводка ивента + последние события из лога |
| `/admin_list` | все участники: логины, id, шары, серии, снежки |
| `/admin_rating` | полный топ по 4 номинациям (не анонимный) |
| `/admin_add` / `/admin_remove <username>` | управление whitelist |
| `/admin_register <id> <Имя>` | принудительная регистрация (после закрытия) |
| `/admin_block` / `/admin_unblock <id>` | блокировка |
| `/admin_log N` | последние N записей журнала событий |
| `/admin_final` | полный reveal итогов |

## Запуск

```bash
cp .env.example .env         # заполнить BOT_TOKEN, ADMIN_IDS, POSTGRES_PASSWORD
docker compose up -d --build tg-bot
docker compose logs -f tg-bot
```

Без Docker: `python main.py` при запущенном PostgreSQL и заполненном `.env`
(схема БД накатывается автоматически при старте).

## Переменные окружения

| Переменная | Значение по умолчанию |
|---|---|
| `TZ_NAME` | Europe/Moscow |
| `BOT_TOKEN` | — (от @BotFather; ADMIN_IDS — Telegram ID у @userinfobot, через запятую) |
| `DECOR_COOLDOWN_HOURS` | 3 |
| `SNOWBALLS_PER_DAY` | 3 |
| `DAY_WINDOW_START` / `DAY_WINDOW_END` | 8 / 23 (часы серии) |
| `REGISTRATION_START/END`, `EVENT_START/END` | 27.11–02.12 / 01.12–31.12 |
| `WHITELIST_FILE` | whitelist_tg.txt (username без `@`) |
| `DECOR_COOLDOWN_MINUTES` | 0 (не задан); тестовая overrides часов; для теста удобно 5 |

> ⚠️ **Тестовый режим (до 30.10.2026):** `DECOR_COOLDOWN_MINUTES=5` в `.env`
> и тестовые даты ивента. Перед прод-запуском 27.11 удалить `DECOR_COOLDOWN_MINUTES`
> и вернуть `DECOR_*` даты ивента.
